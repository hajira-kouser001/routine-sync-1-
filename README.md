## ✨ Features

- **🎓 Academic Tracker:** Keep tabs on coursework, daily study targets, and core BCA milestones.
- **⚡ Quick Presets:** 1-click timer presets for fast logging (Algorithms, Data Structures, Admin Work, Gym, and Running).
- **📊 Daily & Weekly Analytics:** Visual category breakdowns (Study, Exercise, Other) with time tracking insights.
- **💾 Lightweight Database:** Fast, persistent tracking powered by SQLite.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript
- **Database:** SQLite
- **Deployment:** Google Cloud Run (Containerized via Docker)
